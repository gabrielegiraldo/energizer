# Defunct Open Data Communities API functions

Open Data Communities API and Basic Authentication workflow were
replaced by Get energy performance of buildings data API. Use
corresponding `epb_*` function.

## Usage

``` r
odc_set_key(...)

odc_get_data(...)

odc_search_data(...)

odc_bulk_download(...)

odc_get_file_list(...)

odc_get_file(...)

odc_get_meta(...)

odc_get_schema(...)
```

## Arguments

- ...:

  Ignored.

## Value

These functions always throw a defunct-function error.

# Download non-domestic recommendation data

Download non-domestic recommendation data

## Usage

``` r
epb_download_non_domestic_recommendations_json(
  destination_path = ".",
  unzip = FALSE,
  overwrite = FALSE
)
```

## Arguments

- destination_path:

  Directory where ZIP is saved.

- unzip:

  Whether to extract ZIP contents into a sibling directory.

- overwrite:

  Whether to replace an existing ZIP.

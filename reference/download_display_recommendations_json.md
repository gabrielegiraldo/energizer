# Download display recommendation data

Download display recommendation data

## Usage

``` r
download_display_recommendations_json(
  destination_path = ".",
  unzip = FALSE,
  overwrite = FALSE
)
```

## Arguments

- destination_path:

  Directory where ZIP is saved.

- unzip:

  Whether to extract ZIP contents into a sibling directory.

- overwrite:

  Whether to replace an existing ZIP.
